\# OrderFlow



E-Commerce Order Processing API built with Node.js and Express.



\## Project Overview



OrderFlow is a simple e-commerce order processing API created as a hands-on DevOps learning project.



The application allows users to create products and place orders. It also includes basic input validation and order total calculation.



The project will gradually be integrated with DevOps tools and practices such as GitHub, Jenkins, SonarQube, OWASP Dependency Check, Docker, AWS, Terraform, and Kubernetes.
